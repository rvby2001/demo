# Skill: Visual Novel Character Visual Composer

This skill defines a production framework for translating visual novel character profiles into highly consistent 2D sprites, expression sheets, and key art prompts. 

> [!IMPORTANT]
> **Production Boundary (No Agent Image Generation):**
> The agent is solely responsible for decomposing character sheets into consistent, structured visual prompt reference sheets (`<name>-overal-design.md`). 
> **Do NOT invoke or attempt to use any automated or terminal-based image generation tools (such as `generate_image`) during this task.** The human user will copy these compiled prompt sheets to generate the sprites themselves in their preferred external applications (Midjourney, Stable Diffusion, DALL-E 3, etc.) and place the final generated assets in the `project/character/<name>/image/` folder.

### Target Output Location
All outputs generated by this skill must be compiled and saved to:
`project/character/<name>/<name>-overal-design.md` (where `<name>` is the lowercase name of the character's subfolder). This document merges the narrative core of the character-design profile with the visual prompt engineering sheets to create a single master reference sheet.

---

## 1. The Core Challenge: Sprite Consistency
Visual novels require a single character to appear in multiple poses, outfits, and emotional states while maintaining identical facial structure, hair, and clothing details. A naive prompt yields a completely different person each time.

The **Visual Composer** solves this by dividing the image prompt into three modular blocks:
1. **The Style & Production Canvas (Static):** Defines the art style, framing, and isolation requirements.
2. **The Character Identity Anchor (Static):** Defines the immutable features (hair, eyes, facial structure, core clothing).
3. **The Expression & Pose Layer (Dynamic):** Modifies the emotional state, hand positions, and facial quirks.

```
+-------------------------------------------------------------+
| 1. STYLE CANVAS  (e.g., "2D Anime, cell-shaded, clean lines") |
+-------------------------------------------------------------+
| 2. CHARACTER ANCHOR (e.g., "Dorian, silver hair, red coat")  |
+-------------------------------------------------------------+
| 3. EXPRESSION LAYER (e.g., "smirking, adjusting gloves")     |
+-------------------------------------------------------------+
```

---

## 2. The Prompt Anatomy Formula

To generate a visual novel sprite, compile the three modules using the following syntax:

```text
[STYLE CANVAS] [CHARACTER IDENTITY ANCHOR], [EXPRESSION & POSE LAYER], [PRODUCTION SUFFIX]
```

### Module A: Style Canvas (Example)
> *"Visual novel sprite, beautiful 2D anime style, crisp clean line art, soft professional digital painting shading, vibrant color grading, high-end visual novel key art..."*

### Module B: Character Identity Anchor (Example for Dorian Vane)
> *"...a tall 25-year-old male vampire gentleman, sharp aristocratic features, messy silver-white hair swept to the side, glowing crimson eyes, wearing a high-collared dark crimson velvet tailcoat draped over his shoulders, obsidian-black buttoned vest, champagne-gold silk tie..."*

### Module C: Expression & Pose Layer (Dynamic)
This is the only part that changes between assets.
* *Neutral:* *"...lazy lopsided smirk, one eyebrow elegantly arched, looking directly at the viewer..."*
* *Driven:* *"...furious glare, sharp fangs visible, red eyes glowing intensely, clenched jaw..."*

### Module D: Production Suffix (Essential for sprites)
This defines isolated framing and background requirements tailored for crisp transparent cutouts:
> *"...waist-up portrait, isolated on a solid flat high-contrast white background, sharp clean edges, studio lighting, masterpiece, high resolution --no background shadows, gradients, double borders, ornaments"*

> [!TIP]
> **Solid High-Contrast Backgrounds:**
> Always prompt for a pure, flat solid color background (such as `solid flat white background` or a chroma key `solid flat green background`). Avoid patterned, textured, or gradient backgrounds. High-contrast solid backdrops prevent color bleeding on the hair and clothes, making background removal and transparent sprite cutouts pixel-perfect.

## 3. Tool-Specific Consistency Strategies

### A. Midjourney (V6+)
To achieve absolute consistency, use the **Character Reference (`--cref`)** and **Character Weight (`--cw`)** flags.
1. **Step 1: Generate the Baseline Sprite** (e.g., the Neutral expression) against a clean background. Save that image and copy its URL (`URL_A`).
2. **Step 2: Generate Variations** using the exact same prompt structure but modifying the **Expression & Pose Layer**, and appending:
   `--cref URL_A --cw 100` (Maintains both facial features and exact clothing).
3. **Step 3: Modify Poses / Outfits** by changing the clothing description and lowering the weight:
   `--cref URL_A --cw 20` (Maintains only the face/hair structure, allowing clothing changes).

### B. Stable Diffusion (SDXL / WebUI)
1. **ControlNet (IP-Adapter):** Use an IP-Adapter with the baseline sprite to lock in facial structure.
2. **Standardized Seed:** Lock the seed number across generations when making minor facial modifications.
3. **Negative Prompting:** Use a standardized negative prompt block to filter out background elements and style drift:
   `3d, realistic, photorealistic, blurry, soft lines, textured background, complex background, text, signatures, cropping, multiple angles, turnaround`

## 5. Prompt Generator Directives (For AI Gen)
Use this system instruction to prompt an AI model to turn *any* visual novel character sheet into a consistent sprite prompt sheet matching this skill:

```text
You are a Visual Novel Technical Artist and Image Prompt Engineer.
Your task is to take a Character Profile and decompose it into a Visual Composer Sprite Prompt Sheet.
Analyze the character's visual silhouette, attire, colors, expression sheet matrix, and behavioral quirks.
Generate:
1. The Static Style Prefix: Establish a highly aesthetic 2D VN art style.
2. The Static Identity Anchor: Group all permanent physical traits (hair, eyes, face) and clothing details.
3. The Static Production Suffix: Establish isolated framing, flat high-contrast solid backgrounds (such as solid flat white or chroma key green for a clean transparent cutout), and negative prompts/parameters.
4. The Dynamic Expression Prompts: Compose the five exact prompts corresponding to the character's Expression Sheet Matrix (Neutral, Driven, Vulnerable, Shock, and Quirk), inserting the appropriate pose and facial descriptions into the middle of the prompt.
```
